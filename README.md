# Hill Climbing using Reinforcement Learning

This project implements a Hill Climbing optimization strategy in a Reinforcement Learning environment using Gymnasium.

## Overview
The agent learns optimal actions through iterative policy improvement by evaluating rewards and updating parameters using stochastic exploration.

## Technologies Used
- Python
- Gymnasium
- NumPy
- Reinforcement Learning

## Key Concepts
- Reinforcement Learning
- Hill Climbing Optimization
- Policy Evaluation
- Reward Maximization

## How to Run
pip install -r requirements.txt
jupyter notebook
